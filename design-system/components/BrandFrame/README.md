# BrandFrame

The cover and divider device from the brand guide: navy ground, a rounded white outline, small labels set into the top and bottom rules, and a heavy uppercase title.

- **Consumer provides:** `children` (the title, one to three words), optional `label` (top rule) and `footer` (bottom rule, usually the month and year).
- Use for presentation covers, section dividers and campaign title cards. Not for data pages.
- One per page. Keep the labels uppercase and short.
