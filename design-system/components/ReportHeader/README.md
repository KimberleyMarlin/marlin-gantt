# ReportHeader

The navy band that opens every venue report page: venue name, report period and the white Marlin Hospitality logo.

- **Consumer provides:** `title` (venue name, set uppercase automatically), `subtitle` (report and period), `logoSrc` (the URL of `marlin-hospitality-stacked-white.svg` from the Logos group).
- Full-bleed at the top of the page; nothing above it.
- Always the white or cream logo on the band, never the navy one.
- Keep the subtitle to one line: "Week 12 Report (week ended 20 Sep 2026)".
