# Callout

The paired summary panels at the foot of a report page: what's working and what needs attention.

- **Consumer provides:** `tone` (`positive` or `attention`), `title`, and `items` (three short bullets) or `children`.
- Start each bullet with a bold-style keyword ("Loyalty:", "Sales down 12%") and keep it to one line.
- Use them as a pair, side by side, at the end of the page.
