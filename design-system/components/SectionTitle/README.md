# SectionTitle

A numbered section title as the brand guide sets it: condensed numeral, heavy uppercase title, optional navy lead line.

- **Consumer provides:** `title` (written in sentence case, displayed uppercase), optional `number` ("1.1"), optional `lead` (one sentence).
- One per page or slide section. Don't stack two.
- The numeral face, Pressio No.34, isn't loaded yet, so numerals fall back to Work Sans until the font file is added.
