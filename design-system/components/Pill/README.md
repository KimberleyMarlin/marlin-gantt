# Pill

A short chip for a change or a status: deltas next to KPI values, and one-line flags under charts.

- **Consumer provides:** `children` (a few words or a signed number) and `tone`: `positive`, `attention`, `brand` (a neutral headline flag on navy) or `neutral`.
- Keep it to one line. Longer messages belong in a Callout.
- Write the meaning in the pill ("6 reviews awaiting a reply"), so it reads without colour.
